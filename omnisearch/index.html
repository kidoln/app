FAQ

常见问题

OmniSearch 是免费的吗？

完全免费。所有功能全部开放，没有付费墙、订阅或内购，可授权的目录全部支持。

会读取我的文件内容吗？

永远不会。OmniSearch 只访问文件名、路径、大小、时间戳等元数据， 不读取任何文件内容，这是产品的隐私红线。

和 Spotlight 冲突吗？

不冲突。OmniSearch 使用自建的本地索引，完全不依赖也不接管 Spotlight，两个工具可以同时使用、各司其职。

支持搜索哪些目录？

桌面、文稿、下载开箱即用，你也可以授权任意自定义文件夹。 授权通过系统标准面板完成，随时可撤回。

拼音搜索怎么用？

直接输入即可：全拼（xiangmu）或首字母（xm）都能命中「项目」， 无需切换输入法，也无需任何设置。

支持外置硬盘吗？

当前版本聚焦内置目录的极速体验，外置盘与更多目录类型已在路线图中， 会陆续支持。

FAQ

Frequently Asked Questions

Is OmniSearch free?

Completely free. Every feature is unlocked — no paywall, no subscription, no in-app purchases — and every folder you can grant is supported.

Does it read my file contents?

Never. OmniSearch only accesses metadata — names, paths, sizes and timestamps. Reading file contents is the product's privacy red line.

Does it conflict with Spotlight?

No. OmniSearch builds its own local index, doesn't depend on or take over Spotlight. Both tools can run side by side, each doing its own job.

Which folders can I search?

Desktop, Documents and Downloads work out of the box, and you can grant any custom folder. Authorization goes through the system's standard panel and can be revoked anytime.

How does pinyin search work?

Just type: full pinyin (xiangmu) or initials (xm) both match 「项目」— no input-method switching and no setup required.

What about external drives?

The current version focuses on a blazing-fast experience for built-in folders. External drives and more locations are on the roadmap and will be supported over time.
